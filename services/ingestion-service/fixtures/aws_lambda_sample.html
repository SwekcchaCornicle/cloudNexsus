AWS Lambda

What is AWS Lambda?

AWS Lambda is a serverless compute service that runs code in response to events.

You can use Lambda to build applications that respond quickly to new information.

Event source mappings

An event source mapping reads items from a stream or queue and invokes a Lambda function.
